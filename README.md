# MobiLab · Mobility, Faszien & Haltung

Evidenzbasierte, installierbare Web-App (PWA) für ganzkörperliche Mobilisation, myofaszialen Release und Haltungsverbesserung – optimiert für Smartphone und Offline-Nutzung.

## Funktionen
- **65 Übungen** mit eigenständigen, biomechanisch präzisen Schritt-für-Schritt-Anleitungen, Atmung, häufigen Fehlern und Alltags-Alternativen
- **Wissenschaftliche 4-Phasen-Struktur:**
  1. Myofaszialer Release (SMR / Triggerpunkte)
  2. Mobilisation & Dehnung (inkl. PNF)
  3. Neuromuskuläre Aktivierung & Stabilität
  4. Haltungs-Integration (6-Punkte-BodyMap)
- **Modularer Baukasten** mit Smart-Generator (Regionen, Phasen, Equipment, Zieldauer) und Phase-1→3-Sortierung
- **Hands-Free-Timer** mit automatischem Seitenwechsel (`Links` → `10 s Wechselpause` → `Rechts`), PNF-/Intervall-Subphasen, Web-Audio-Gong und Screen Wake Lock
- **PWA:** Direkt über Chrome (Android) oder Safari (iOS) auf dem Startbildschirm installierbar und offline nutzbar
